# SiteFooter

The footer with the joke (FR-JOKES-01) and the data credits with links (BC-BRAND-02). It sits on the sky.

- Provide `joke`: one or two calm sentences, picked deterministically from a local list in `lib/` (no API, no tracking).
- Credits are fixed: «Дані погоди: Open-Meteo · Карта: © OpenStreetMap contributors», both linked and underlined.
